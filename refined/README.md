
* **refill_check.py** > This script identifies truly new drug initiations by checking REFILL=0 prescriptions against historical records (2014-present), flagging each based on prior drug history: FLAG=NULL indicates no prior history, FLAG=0 indicates same-year duplicates, and negative flags indicate years since last prescription. 
* **sample_merge9.py** > This script identifies truly new prescriptions (FLAG = NULL) and matches each to the closest physician visit(s) in time, calculating unique physician counts and temporal distances, then outputs histogram summaries and detailed prescription event files for downstream analysis.
* **merge_ndcnum.py** > Filters prescription events to single-physician visits within 60 days, enriches them with NDC drug codes, and flags semaglutide prescriptions, outputting prescription_events_YYYY_##_with_ndcnum.parquet files.
* **merge_diag.py** > Adds diagnosis-based eligibility flags using only pre-June 2021 diagnosis history for adult patients (18+ by June 2021) to establish baseline patient composition. Queries inpatient file (CCAE_I.parquet) for diabetes or obesity diagnosis codes where ADMDATE < '2021-06-01' and DOBYR <= 2002, creating binary eligibility flags reflecting adult patient health status before semaglutide adoption period.
* **phys_id_semaglutide_history.py** > Aggregates individual prescription events to physician-level metrics in two stages: (1) groups by physician-date, calculating patient counts, semaglutide prescriptions, and eligibility (diabetes OR obesity diagnosis); (2) aggregates to physician-month level, summing metrics across dates within each month.
